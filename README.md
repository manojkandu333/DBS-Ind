# DBS Butterfly Demo

A simple installable mobile banking interface demo built for practice and familiarization.

## Butterfly Version

This version uses:

- Yellow and gold themed interface
- Black and red app icon
- White butterfly symbol in the center
- App name: **DBS**
- Installable from GitHub Pages as a PWA

## Included Files

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `README.md`

## Install on GitHub Pages

Upload all files to the root of the GitHub repository.

Make sure the main page is named exactly:

`index.html`

Then go to:

**Settings → Pages → Deploy from a branch → main → / (root)**

After GitHub Pages finishes deployment, open the site on your phone.

### Samsung Internet

Open the menu and choose:

**Add page to → Home screen**

### Chrome

Open the menu and choose:

**Add to Home screen** or **Install app**

If an older version is already installed, remove the old home-screen app/shortcut first and then install this version again so the butterfly icon refreshes.

## Important

This project is a standalone demo interface. It is not connected to DBS Bank, UPI, or any real banking service and does not perform real transactions.
